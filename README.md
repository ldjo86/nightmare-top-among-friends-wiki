## Ce que ce projet apporte

- Adventure and RPG, Multiplayer et Vanilla+ dans les catégories de la fiche
- Profil orienté vers les sessions entre amis
- Base Fabric 1.21.11 annoncée
- Composition exacte du modpack et configurations non vérifiées tant que son manifeste n'est pas disponible

## 🚀 Premiers pas

1. Retrouve **Nightmare Top Among Friends** sur le [profil CurseForge de l'auteur](https://www.curseforge.com/members/joranne/projects).
2. Installe la version Fabric 1.21.11 annoncée avec ton lanceur.
3. Vérifie la version du serveur et des clients avec tes amis.
4. Teste sur un nouveau monde ou une sauvegarde avant de commencer votre aventure.

## 1. Importer le modpack plutôt que mélanger des versions

Retrouve le projet sur le profil CurseForge de son auteur, puis installe-le avec le lanceur CurseForge ou un lanceur prenant en charge son format. N'assemble pas arbitrairement une liste de mods d'après son titre.

## 2. Préparer une partie entre amis

Choisissez ensemble les mêmes versions Minecraft, les mêmes fichiers de modpack et les paramètres appropriés au serveur. Testez la connexion avant de commencer une partie longue.

## 3. Protéger vos mondes

Avant de transférer un monde existant dans un profil plus difficile, effectuez une sauvegarde. Les configurations et dépendances exactes doivent être lues dans le manifeste du pack une fois obtenu.

## 4. Découvrir le contenu en jouant

Le projet annonce une expérience Nightmare entre amis ; les événements et créatures ne sont pas prévisualisés sans sources vérifiées. Ce wiki ne prétend pas connaître la liste des mods tant que le manifeste n'a pas été audité.
